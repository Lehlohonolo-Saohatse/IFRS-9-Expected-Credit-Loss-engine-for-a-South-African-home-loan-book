# IFRS-9-Expected-Credit-Loss-engine-for-a-South-African-home-loan-book
An IFRS 9 ECL framework on a simulated SA mortgage book driven by SARB and Stats SA macro data, covering lifetime PD, LGD, EAD, staging and probability-weighted scenarios. Validated out-of-time and backtested predicted vs realised losses; documented methodology, assumptions and limitations in a model development document.
